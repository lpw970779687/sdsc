# 水浒传108位好汉全维度档案

本文整理自《水浒传》百回本原著，按梁山忠义堂石碣座次排序，覆盖三十六天罡星与七十二地煞星。每人包含发型、脸型、穿着、武器、坐骑、主要事迹、人物结局七项信息，部分次要人物原著无明确记载处，结合绰号内涵与经典文学形象合理补全。

## 一、三十六天罡星（座次 1-36）

1. **天魁星·呼保义 宋江**
   - 发型：成年男子束发，日常戴皂纱唐巾，留三牙掩口短髭，胡须修剪整齐
   - 脸型：方额阔脸，唇方口正，额阔顶平，面色偏黑
   - 穿着：平日穿素色布袍，郓城县任押司时穿青绿色公服；上山后常穿暗纹锦缎长袍，临阵披软甲、系鸾带
   - 武器：随身佩腰刀，偶用朴刀，极少亲自上阵肉搏
   - 坐骑：无固定专属名马，征战时骑寻常战马；攻破曾头市后获照夜玉狮子马
   - 主要事迹：原为郓城县押司，私放晁盖等七星聚义；怒杀阎婆惜后流落江湖；浔阳楼题反诗被判死刑，梁山劫法场后正式上山；坐上梁山头把交椅，力主招安；率梁山军征辽、征方腊，屡立战功
   - 人物结局：征方腊后授楚州安抚使兼兵马都总管，被高俅、蔡京等奸臣以御酒毒杀，死后葬于蓼儿洼

2. **天罡星·玉麒麟 卢俊义**
   - 发型：束发戴束发金冠，留八字长眉，三牙髭须整洁
   - 脸型：长方脸，面白如玉，目炯双瞳，器宇轩昂
   - 穿着：平日穿绣金团花锦袍，上阵披熟钢鱼鳞铠甲，外罩素白战袍，腰系狮蛮宝带
   - 武器：麒麟黄金矛，惯用棍棒，有“棍棒天下无对”之称
   - 坐骑：千里龙驹麒麟兽，通体雪白高头大马
   - 主要事迹：河北大名府富商，被吴用设计赚上梁山；活捉史文恭，为晁盖报仇；梁山排名第二，为兵马副元帅；招安后随军征战，屡建奇功
   - 人物结局：征方腊后授庐州安抚使，被奸臣下水银毒伤，乘船时失足落水溺亡

3. **天机星·智多星 吴用**
   - 发型：书生束发，戴桶子样抹眉梁头巾，留细长胡须
   - 脸型：清瘦长脸，面白眉清，眼神精明锐利
   - 穿着：常年穿皂沿边麻布宽衫，腰系茶褐銮带，白袜布鞋；后期也常着道家装束
   - 武器：手持羽扇，腰悬铜链，基本不近身肉搏
   - 坐骑：寻常战马，极少冲锋陷阵
   - 主要事迹：东溪村教书先生，策划智取生辰纲；为梁山军师，屡出奇谋，奠定梁山基业；全力支持宋江招安，随军征战出谋划策
   - 人物结局：征方腊后授武胜军承宣使，得知宋江死讯后，与花荣一同在宋江墓前自缢身亡

4. **天闲星·入云龙 公孙胜**
   - 发型：头绾两枚双丫髻，以黑丝绦束发，留落腮胡须
   - 脸型：四方脸，杏子眼，八字眉，相貌清癯
   - 穿着：身穿短褐道袍，背背松纹古铜剑，脚穿麻鞋，一派仙风道骨
   - 武器：松纹古定剑，能施法呼风唤雨
   - 坐骑：寻常战马，更多以道法遁行
   - 主要事迹：道号一清先生，七星聚义成员之一；多次以道术破敌，斗法破高廉、收樊瑞；梁山排名第四，掌管机密军师
   - 人物结局：征方腊前回乡侍母修道，最终归隐山林，得道善终

5. **天勇星·大刀 关胜**
   - 发型：束发戴熟钢狮子盔，留细细三柳髭髯
   - 脸型：长红脸，面如重枣，唇若涂朱，凤眼朝天，两眉入鬓，酷似先祖关羽
   - 穿着：上阵披连环锁子黄金甲，外罩绿锦战袍，腰系镀金带
   - 武器：青龙偃月刀（又名冷艳锯）
   - 坐骑：卷毛赤兔马，日行千里
   - 主要事迹：蒲东巡检，关羽后代；奉命征梁山，被设计收服；梁山马军五虎将之首，武艺超群
   - 人物结局：征方腊后授大名府正兵马总管，一日酒醉失足落马，得病而死

6. **天雄星·豹子头 林冲**
   - 发型：束发戴铁盔，留燕颔虎须，毛发刚硬
   - 脸型：豹头环眼，脸型刚猛，颔下虎须浓密
   - 穿着：禁军教头常穿皂色公服，上阵披寒铁铠甲，外罩青罗战袍
   - 武器：丈八蛇矛
   - 坐骑：惯骑烈马，无专属名马记载，上阵乘青白战马
   - 主要事迹：原八十万禁军枪棒教头，被高俅陷害误入白虎堂，刺配沧州；风雪山神庙后被逼上梁山；火并王伦拥立晁盖，梁山马军五虎将第二
   - 人物结局：征方腊途中患风瘫，留六和寺养病，半年后病逝

7. **天猛星·霹雳火 秦明**
   - 发型：束发戴朱红漆笠盔，落腮胡须张扬
   - 脸型：方脸阔口，面色赤红，性情急躁自带煞气
   - 穿着：全身绛红色战甲，外罩大红战袍，狮蛮宝带束腰
   - 武器：狼牙烽火棒
   - 坐骑：胭脂赤马
   - 主要事迹：原青州指挥司总管，性如烈火；被宋江设计逼上梁山；梁山马军五虎将第三，冲锋陷阵总是当先
   - 人物结局：征方腊时战死于清溪县，被方杰一戟刺于马下

8. **天威星·双鞭 呼延灼**
   - 发型：束发戴干红凹面巾盔，络腮胡须整齐
   - 脸型：圆脸耳大，面容刚正，有开国名将气度
   - 穿着：上阵披乌油七星铠，外罩绿罗团花战袍
   - 武器：两条水磨八棱钢鞭（左手重十二斤，右手重十三斤）
   - 坐骑：踢雪乌骓马，通体乌黑唯四蹄雪白
   - 主要事迹：开国名将呼延赞后代，汝宁郡都统制；奉命征梁山，连环甲马被破后归降；梁山马军五虎将第四
   - 人物结局：征方腊后授御营兵马指挥使，后率军与金军作战，阵亡于淮西

9. **天英星·小李广 花荣**
   - 发型：少年束发，戴烂银盔，发鬓整齐
   - 脸型：俊朗长脸，齿白唇红，双眉入鬓，双目有神
   - 穿着：上阵披白银铠甲，外罩素白袍，细腰宽膀，少年英武
   - 武器：雪山飞龙枪，天地日月弓，配雕翎箭百发百中
   - 坐骑：银鬃白马
   - 主要事迹：原清风寨武知寨，宋江好友；箭术无双，人称“小李广”；梁山马军八骠骑兼先锋使之首
   - 人物结局：征方腊后授应天府兵马都统制，得知宋江死讯，与吴用一同自缢于宋江墓前

10. **天贵星·小旋风 柴进**
    - 发型：束发戴皂纱簇花软巾，三牙掩口髭须
    - 脸型：长方脸，龙眉凤目，皓齿朱唇，贵气逼人
    - 穿着：常穿紫绣团花战袍，腰系玲珑白玉带，脚穿皂靴，皇族世家打扮
    - 武器：长枪，较少亲自上阵厮杀
    - 坐骑：高头俊马，鞍辔华贵
    - 主要事迹：后周世宗柴荣后代，家有丹书铁券；专爱结交天下好汉，资助过林冲、宋江等人；梁山掌管钱粮头领
    - 人物结局：征方腊后授横海军沧州都统制，后辞官回乡，无疾而终

11. **天富星·扑天雕 李应**
    - 发型：束发戴铁盔，留短须
    - 脸型：虎头燕颔，鹘眼鹰睛，面色沉稳
    - 穿着：上阵披铁甲，外罩锦袍，背藏飞刀
    - 武器：点钢枪，背藏五把飞刀，能百步取人
    - 坐骑：高头大马
    - 主要事迹：原李家庄庄主，与祝家庄、扈家庄结盟；被宋江设计赚上梁山；与柴进一同掌管梁山钱粮
    - 人物结局：征方腊后授中山府郓州都统制，后辞官回乡，善终

12. **天满星·美髯公 朱仝**

    - 脸型：长红脸，面如重枣，目若朗星，相貌酷似关羽
    - 穿着：常穿绿锦战袍，上阵披锁子甲，气度磊落
    - 武器：九龙朝阳刀
    - 坐骑：赤红战马
    - 主要事迹：原郓城县马兵都头，先后义释晁盖、宋江、雷横；被逼上梁山后，为马军八骠骑兼先锋使
    - 人物结局：征方腊后授保定府都统制，后随刘光世破金，官至太平军节度使

13. **天孤星·花和尚 鲁智深**

    - 穿着：身披皂色僧袍，腰系鸦青绦，背上刺有花绣
